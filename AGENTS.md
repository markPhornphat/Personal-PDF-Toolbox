# PDF Toolbox

- Keep PDF processing local and keep GitHub connections in the opt-in updater.
- Preserve source PDFs and stage exports before publishing them.
- Use the locked Windows environment with `uv sync --locked`.
- Run Ruff, mypy and pytest before packaging.
- Update the feature matrix when implementation or test status changes.
- Use the shared mascot modal for actionable errors and warnings in every tool. Explain what happened and give the user a concrete next step. Keep routine progress and success feedback inline.
- Obtain authorization before pushing or publishing.
