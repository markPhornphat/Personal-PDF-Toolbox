# PDF Toolbox user guide

[คู่มือภาษาไทย](USER_GUIDE_TH.md)

Run PDF-Toolbox-Setup-x64.exe, choose where to install, and open PDF Toolbox from the Start menu. The installer includes the PDF tools and their runtime. If Windows shows a publisher prompt, verify the installer with the person who provided it.

Drop files on Home or choose Browse files. You can also copy a file in File Explorer and press Ctrl+V in PDF Toolbox.

- **Merge / Append** arranges pages from several PDFs. Add files in order, drag pages or use the arrow buttons, then export the combined PDF.
- **Split PDF** exports individual pages, fixed-size groups, custom ranges or groups separated at selected boundaries. Enter custom groups such as `1-3;4-6`. Choose ZIP to save the resulting files in one archive.
- **Remove / Extract** selects pages with Ctrl or Shift. Use the action menu to remove them, extract them to one PDF, or export a file per selected page.
- **PDF to JPG / PNG** exports all pages, a selection or a typed range. Select a DPI preset and format, then choose a destination folder.
- **Edit PDF** opens the visual editor. Choose Text or a shape and click or drag on the page. Write in the object properties panel. Paste a screenshot with Ctrl+V or drag a JPG or PNG onto the page. Drag to move objects and use the blue corner handle to resize them. Save a copy with Save As.

Choose a new filename when exporting a PDF. Original files stay in place.

Update checks can be enabled in Settings for a configured build. Choose **Update now** to download a verified release, then **Ready to install** when you can finish editing. Turn off background checks in Settings at any time.

To uninstall, open **Windows Settings → Apps → Installed apps**, locate PDF Toolbox and choose **Uninstall**. Saved PDFs and application preferences are kept.
